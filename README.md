# HOMELY SAS — Prototipo navegable

Abra `index.html` en un navegador. Es una demostración visual: los formularios no guardan datos ni realizan pagos.

Flujos incluidos:

- Público: inicio → registro/inicio de sesión → términos, privacidad y preguntas frecuentes.
- Cliente: inicio → solicitar servicio (descripción, ubicación, pago) → seguimiento → solicitudes y mensajes.
- Técnico: inicio de sesión como técnico → verificación (identidad, experiencia, disponibilidad, estado) → inicio profesional → solicitud entrante → servicio en curso.
- Técnico: navegación a billetera, mensajes y configuración.

La pantalla de estado de aprobación representa una verificación aprobada para permitir demostrar el recorrido completo del técnico.
